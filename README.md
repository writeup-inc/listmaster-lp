# リストマスター LP（GitHub Pages 公開用）

営業リスト自動生成AI「リストマスター」のランディングページ。

- 公開URL: https://writeup-inc.github.io/listmaster-lp/
- 提供元: 株式会社ライトアップ
- 構成: 単一の `index.html`（外部依存なし・インラインCSS/SVG・ライト/ダーク対応）

## 特徴

既存LP（Figma Sites 版）をベースに、対談で語られた営業論を
「COLUMN ── 営業の考え方」として独立セクションに追加している。

1. 新規の売上は、掛け算でできている（新規リード × 受注率 × 単価）
2. 打率は変えられない。変えられるのは、母数と、誰に当たるか
3. 人が見つける会社は、競合も見つけている

## 編集

`index.html` を直接編集して push すると、GitHub Pages に自動反映される。

## 注意

- 価格は掲載していない（確定後に追記する）
- CTA はメール（info@writeup.co.jp）と電話に一本化している。
  ウェビナー申込の実URLが決まったら、主CTAをそちらへ差し替える
